# Ex. No. 2 - SIMULATION ANALYSIS ON SLIDER CRANK MECHANISM

## DATE: 10:03:2026

## AIM:
###   To determine & simulate the displacement & velocity analysis for the given slider crank mechanism. 
###   An engine mechanism is shown. The Crank CB = 200mm and the connecting rod BA = 600mm. In the position shown, the crankshaft has a speed of 50 rad/s and an angular acceleration of 800 rad/s2


## REQUIREMENTS:
###   ●	Mech Analyzer software.
###   ●	Processor: Minimum 1.5 GHz
###   ●	RAM: Minimum 512 MB
###   ●	Operating System: Windows XP, Windows Vista, Windows 7, Windows 8 or higher.
###   ●	Dependencies: Microsoft .Net 2.0 framework
###   ●	Mini Drafter.
###   ●	Geometry instruments.

## PROCEDURE:
###  Configuration diagram
### 1.Assume the scale
Assume a scale of 1:10 for the drawing. Draw a horizontal reference line on the sheet and mark a point C on this line.

### 2.Draw line CB at 120°
At point C, use a protractor to construct a line inclined at an angle of 120° to the horizontal line.
Measure 20 mm along this inclined line using a ruler and mark the endpoint as B. Join C and B to form line CB.

### 3.Locate point A using an arc
Place the compass needle at point B and set the radius to 60 mm.
With B as the centre, draw an arc that intersects the horizontal line.
Mark the point of intersection as A.

### 4.Complete the configuration diagram
Join B and A with a straight line using a ruler.
The configuration diagram is now completed.

## Velocity diagram
### Locate the fixed point in the velocity diagram
Since point C is a fixed point, its velocity is zero. Therefore, in the velocity diagram, point c represents the stationary point and is taken as the origin (reference point).

### 1.Draw vector bc
From point c, draw a vector bc with a length of 100 mm.
This line should be drawn perpendicular to the crank CB as shown in the configuration diagram. This represents the velocity of point B with respect to C.

### 2.projection from point b
From point b, draw a projection line perpendicular to link AB based on the direction of AB in the configuration diagram. This line represents the direction of velocity of point A with respect to B.

### 4.Locate point a and complete the diagram
From point c, draw a horizontal line.
The point where this horizontal line intersects the projection drawn from b is marked as point a.

### 5.Complete the velocity diagram
Join c and a with a straight line.
The triangle cba now represents the velocity diagram of the mechanism.
